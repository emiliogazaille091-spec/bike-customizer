# Bike Customizer

A just-for-fun website where you build your own custom bike from real parts (Shimano, SRAM, Fox, Zipp, Maxxis and more), see it drawn as you choose, and get an approximate price.

**Live site:** https://emiliogazaille091-spec.github.io/bike-customizer/

Prices are rough US retail estimates. This is not a store and is not connected to any of the brands shown.
